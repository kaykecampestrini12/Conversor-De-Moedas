# 💱 Conversor de Moedas

Projeto desenvolvido com HTML, CSS e JavaScript para conversão de moedas em tempo real utilizando a AwesomeAPI.

## 📸 Preview

<img width="1920" height="903" alt="projeto Convert Money" src="https://github.com/user-attachments/assets/36418980-6c59-4aed-997e-c6bd99c2d479" />


## 🚀 Funcionalidades

- Conversão de moedas em tempo real
- Interface simples e responsiva
- Consumo de API para obter cotações atualizadas

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- AwesomeAPI

## ⚙️ Como Executar

Clone o repositório:

```bash
git clone https://github.com/kaykecampestrini12/Conversor-De-Moedas.git
```

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server do VS Code.
