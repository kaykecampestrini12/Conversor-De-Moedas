<h1 >Conversor de Moedas</h1>


<h2>Sobre o Projeto:</h2>
<br>
<p>Esse é um projeto que aprendi no curso DevClub Front-End, onde adquiri conhecimento em JavaScript, e pratiquei lógica de programação.</p>
<p>Fiz um sistema que converte a moeda BRL para as seguintes opções: Dolar, Euro, BitCoin.</p>
<p>para converter é facil, basta o usuario escolher a opção da moeda que ele quer converter, e logo em seguida digitar o valor que deseja converter. Apoós isso clique no botão <b>Converter, e pronto, la vai estar seu resultado.</p>
